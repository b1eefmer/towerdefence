# Tower Defence - документация проекта

## Обзор

`towerdefence` - это 2D-игра жанра Tower Defense на Unity. Игрок защищает базу от волн врагов, строит башни на специальных площадках, зарабатывает золото за уничтожение противников и улучшает уже построенные башни.

Основной игровой цикл:

1. Игрок выбирает тип башни в меню магазина.
2. Игрок ставит башню на доступный `Plot`.
3. Нажатие кнопки `Start` запускает волну врагов.
4. Враги идут от стартовой точки по маршруту к базе.
5. Башни автоматически ищут врагов в радиусе и атакуют их.
6. Уничтоженные враги дают золото.
7. Если враг доходит до базы, база теряет жизнь.
8. После зачистки волны игрок получает дополнительный доход и готовится к следующей волне.
9. После последней волны показывается экран победы, при потере всех жизней - экран поражения.

## Сцены

### MainMenu

Главное меню игры. Скрипт `MainMenu` обрабатывает кнопки:

- `PlayGame()` - загружает `SampleScene`.
- `Options()` - загружает `OptionsScene`.
- `LoadGame()` - загружает сохранение через `SaveSystem`.
- `QuitGame()` - выходит из игры или останавливает Play Mode в редакторе.

Кнопка загрузки становится активной только если найден файл сохранения.

### SampleScene

Первый игровой уровень. Использует стандартный маршрут из `LevelMananger.path`. Враги появляются в `LevelMananger.startPoint`, затем идут по массиву waypoint-точек.

Ключевые объекты уровня:

- `LevelMananger` - хранит стартовую точку, путь врагов и золото игрока.
- `EnemySpawner` - управляет волнами, спавном и статистикой.
- `BuildMananger` - хранит доступные башни и текущий выбор игрока.
- `UIManager` - блокирует строительство при клике по интерфейсу.
- `Path` - набор waypoint-точек.
- `Plots` - площадки для строительства.
- `Start` - кнопка запуска волны.
- `Menu` / `Menu Toggle` - магазин башен и его раскрытие.
- `PauseGameButton` - кнопка паузы.

### FireScene

Второй игровой уровень с отдельной логикой маршрутов. `EnemySpawner` пытается найти три маршрута по именам:

- `Path`, `Path 1`, `Path1`, `Route`, `Route 1`, `Route1`
- `Path (1)`, `Path 2`, `Path2`, `Route (1)`, `Route 2`, `Route2`
- `Path (2)`, `Path 3`, `Path3`, `Route (2)`, `Route 3`, `Route3`

Для `FireScene` волны строятся расписанием `BuildFireWaveSchedule()`: враги появляются на разных маршрутах с заданными задержками. Если в сцене нет заранее настроенной базы, `LevelMananger` создает runtime-объект `Base` и UI с сердцами.

### PauseScene и OptionsScene

Дополнительные сцены для меню паузы и настроек. Фактическая пауза во время игры создается скриптом `PauseManager` поверх текущей игровой сцены.

## Основные игровые системы

## Управление уровнем и валютой

Класс: `LevelMananger`

> В коде имя класса написано как `LevelMananger`, а не `LevelManager`. Это важно при поиске ссылок.

Основные поля:

- `startPoint` - точка появления врагов в обычном уровне.
- `path` - массив waypoint-точек маршрута.
- `currency` - текущее золото игрока.

Основные методы:

- `IncreaseCurrency(int amount)` - добавить золото.
- `SetCurrency(int amount)` - установить золото, не ниже нуля.
- `SpendCurrency(int amount)` - попытаться потратить золото.

На старте игрок получает `1000` золота. В `Update()` скрипт обновляет HUD золота и обрабатывает fallback-клики по UI-кнопкам, чтобы интерфейс работал даже при проблемах с привязками событий.

## Волны врагов

Класс: `EnemySpawner`

`EnemySpawner` хранит массив префабов врагов и план волн. В обычной сцене волны описаны массивом `wavePlan`, где числа являются индексами врагов в `enemyPrefabs`.

Параметры:

- `timeBetweenWaves` - задержка перед показом кнопки следующей волны.
- `maxWaves` - максимальное количество волн, сейчас `10`.
- `currencyIncome` - награда за завершенную волну, сейчас `30`.

Логика:

- `StartWaveFromButton()` запускает волну кнопкой.
- `StartWave()` скрывает кнопку старта и подготавливает счетчики.
- `SpawnEnemy()` создает врага.
- `EnemyDestroyed()` уменьшает количество живых врагов.
- `EndWave()` выдает награду и открывает следующую волну.
- `Winner()` показывает экран победы после последней волны.

Статистика матча:

- общее количество убийств;
- заработанное золото;
- время игры;
- текущая волна;
- оставшиеся враги.

## Враги и движение

Класс: `EnemyMovement`

Враг движется к текущей waypoint-точке через `Rigidbody2D.linearVelocity`. Когда он достигает точки, переходит к следующей. Если маршрут закончился, враг наносит базе `1` урон, вызывает событие уничтожения врага и удаляется.

Важные методы:

- `UpdateSpeed(float newSpeed)` - изменить скорость.
- `ResetSpeed()` - вернуть базовую скорость.
- `RestoreState(...)` - восстановить врага из сохранения.
- `SetHardcodedPath(...)` - назначить маршрут вручную, используется в `FireScene`.

Класс: `Health`

Отвечает за здоровье врагов:

- `hitPoint` - количество HP.
- `currencyWorth` - награда за убийство.
- эффекты попадания: вспышка, `HitSpark`, floating text;
- звуки попадания и смерти.

При смерти враг:

1. вызывает `EnemySpawner.onEnemyDestroy`;
2. добавляет золото игроку;
3. добавляет статистику через `EnemySpawner.AddStats`;
4. уничтожает объект.

## База игрока

Класс: `BaseHealth` в файле `Base.cs`

База имеет ограниченное количество жизней. При достижении врагом конца пути вызывается `TakeDamage(1)`.

Основные поля:

- `maxLives` - максимальное количество жизней.
- `currentLives` - текущие жизни.
- `hearts` - UI-иконки жизней.
- `gameOverUI` - экран поражения.

Когда жизни заканчиваются, `GameOver()`:

- собирает статистику из `EnemySpawner`;
- останавливает музыку;
- проигрывает звук поражения;
- показывает `GameOverUI`;
- ставит `Time.timeScale = 0f`.

## Строительство башен

Класс: `BuildMananger`

> В коде имя класса написано как `BuildMananger`, а не `BuildManager`.

Скрипт хранит массив `Tower[] towers`. Каждый `Tower` содержит:

- `name` - название башни;
- `cost` - стоимость;
- `prefab` - префаб башни.

Кнопки выбора башен привязываются по именам:

- `Basic Turret` -> индекс `0`
- `Sniper Turret` -> индекс `1`
- `Slowmo Turret` -> индекс `2`

Класс: `Plot`

`Plot` - площадка для строительства. При клике:

- если на площадке уже есть башня, открывается UI улучшения;
- если строительство запрещено, выводится сообщение;
- если у игрока недостаточно золота, покупка отменяется;
- если золота хватает, выбранная башня создается на позиции площадки.

Цвет площадки меняется при наведении и после строительства.

## Башни

### Обычные атакующие башни

Класс: `Turret`

Башня автоматически ищет врага в радиусе `targetingRange` через `Physics2D.CircleCastAll`, поворачивается к цели и стреляет с частотой `bps` bullets per second.

Основные поля:

- `turretRotationPoint` - часть башни, которая поворачивается к врагу.
- `enemyMask` - слой врагов.
- `bulletPrefab` - снаряд.
- `firingPoint` - точка вылета снаряда.
- `targetingRange` - радиус атаки.
- `rotationSpeed` - скорость поворота.
- `bps` - выстрелов в секунду.
- `baseUpgradeCost` - базовая стоимость улучшения.

Улучшение:

- открывается через клик по построенной башне;
- показывает текущий уровень и стоимость;
- тратит золото;
- увеличивает уровень;
- пересчитывает скорострельность по формуле `bpsBase * level^0.6`;
- показывает индикатор радиуса атаки.

Стоимость улучшения считается как:

```text
baseUpgradeCost * level^0.8
```

### Slowmo-башня

Класс: `TurretSlowmo`

Эта башня не стреляет снарядами. Она периодически ищет всех врагов в радиусе и снижает их скорость до `0.5` на время `freezeTime`, затем вызывает `ResetSpeed()`.

Параметры:

- `targetingRange` - радиус действия.
- `aps` - применений эффекта в секунду.
- `freezeTime` - длительность замедления.

## Снаряды

Класс: `Bullet`

Снаряд получает цель через `SetTarget(Transform target)`, летит к ней с помощью `Rigidbody2D.linearVelocity` и при столкновении вызывает `Health.TakeDamage(bulletDamage)`.

Параметры:

- `bulletSpeed` - скорость полета.
- `bulletDamage` - урон.

## Пользовательский интерфейс

### Магазин башен

Класс: `Menu`

Отвечает за раскрытие и закрытие магазина через Animator-параметр `MenuOpen`. Также обновляет текст золота.

Методы:

- `ToogleMenu()` - переключает состояние меню.
- `ToggleMenu()` - альтернативное имя для того же действия.

### UI-блокировки

Класс: `UIManager`

Не дает строить башни, если курсор находится над UI. Проверяет:

- `Menu`
- `Menu Toggle`
- `PauseGameButton`
- `Start`
- активные панели улучшения башен

### Экран поражения

Класс: `GameOverUI`

Показывает:

- количество убитых врагов;
- заработанное золото;
- время игры.

Кнопки:

- restart - перезапуск текущей сцены;
- exit, quit или menu - выход в `MainMenu`.

### Экран победы

Класс: `WinnerUI`

Показывает статистику победы и останавливает время. Кнопки:

- next - следующий уровень через `LevelManager.LoadNextLevel()`;
- restart - перезапуск сцены;
- exit, quit или menu - выход в `MainMenu`.

## Пауза

Класс: `PauseManager`

`PauseManager` является singleton-объектом и сохраняется между сценами через `DontDestroyOnLoad`. Пауза доступна только в:

- `SampleScene`
- `FireScene`

При паузе скрипт:

1. делает скриншот текущего экрана;
2. создает затемненный и размытый overlay;
3. создает кнопки `Resume`, `Save`, `Back`;
4. скрывает кнопку паузы;
5. ставит `Time.timeScale = 0f`.

Действия:

- `ResumeGame()` - продолжить игру.
- `SaveGame()` - сохранить состояние.
- `LoadGame()` - загрузить сохранение.
- `BackToMenu()` - вернуться в главное меню.

## Сохранение и загрузка

Класс: `SaveSystem`

Сохранение записывается в:

```text
Application.persistentDataPath/savegame.json
```

Сохраняются:

- имя текущей сцены;
- золото;
- текущая волна;
- количество врагов, оставшихся для спавна;
- количество живых врагов;
- индекс следующего спавна;
- состояние спавнера;
- статистика убийств, золота и времени;
- жизни базы;
- построенные башни, их позиции, типы и уровни;
- живые враги, их позиции, HP, скорость и текущий индекс маршрута.

Загрузка:

1. читает JSON;
2. загружает сохраненную сцену;
3. после загрузки восстанавливает менеджеры;
4. очищает площадки;
5. восстанавливает башни;
6. восстанавливает врагов;
7. восстанавливает состояние `EnemySpawner`.

## Переход между уровнями

Класс: `LevelManager` в файле `Levels.cs`

Хранит список игровых уровней:

```text
SampleScene -> FireScene
```

Метод `LoadNextLevel()` загружает следующий уровень. Если в сцене есть `LevelTransition`, используется анимация перехода.

Класс: `LevelTransition`

Делает визуальный переход:

1. камера приближается к центру текущего уровня;
2. показывается flash-эффект;
3. камера отъезжает к центру следующего уровня;
4. загружается следующая сцена.

## Настройка нового уровня

Минимальный набор объектов для нового уровня:

1. Создать сцену и добавить ее в Build Settings.
2. Добавить `LevelMananger`.
3. Назначить `startPoint`.
4. Создать объект `Path` с waypoint-точками и назначить их в `LevelMananger.path`.
5. Добавить `EnemySpawner` и заполнить `enemyPrefabs`.
6. Добавить `BuildMananger` и заполнить массив `towers`.
7. Разместить `Plot`-объекты в местах, где можно строить башни.
8. Добавить базу с `BaseHealth` и UI-сердцами.
9. Добавить Canvas с кнопками `Start`, `PauseGameButton`, `Menu Toggle` и кнопками выбора башен.
10. Добавить `UIManager`.

Для уровня по типу `FireScene` нужно дополнительно создать три маршрута с именами `Path`, `Path (1)` и `Path (2)` или совместимыми вариантами имен.

## Расширение игры

### Добавить новую башню

1. Создать prefab башни.
2. Добавить на prefab `Turret` или новый скрипт атаки.
3. Настроить радиус, скорострельность, цену улучшений, снаряд и слой врагов.
4. Добавить башню в массив `BuildMananger.towers`.
5. Создать кнопку выбора башни в UI.
6. Если имя кнопки не входит в текущий список (`Basic Turret`, `Sniper Turret`, `Slowmo Turret`), расширить `TryGetTowerIndexForButton()`.

### Добавить нового врага

1. Создать prefab врага.
2. Добавить `EnemyMovement`, `Health`, `Rigidbody2D`, Collider2D.
3. Настроить скорость, HP и награду.
4. Добавить prefab в массив `EnemySpawner.enemyPrefabs`.
5. Включить индекс врага в `wavePlan` или расписание `FireScene`.

### Изменить баланс

Основные точки баланса:

- стартовое золото: `LevelMananger.Start()`;
- награда за волну: `EnemySpawner.currencyIncome`;
- план волн: `EnemySpawner.wavePlan`;
- награда за врага: `Health.currencyWorth`;
- HP врага: `Health.hitPoint`;
- цена башни: массив `BuildMananger.towers`;
- стоимость улучшения: `Turret.baseUpgradeCost`;
- рост скорострельности: `Turret.CalculateBPS()`;
- жизни базы: `BaseHealth.maxLives`.

## Известные особенности кода

- В именах классов есть опечатки: `LevelMananger` и `BuildMananger`.
- Файл `Base.cs` содержит класс `BaseHealth`, поэтому имя файла и имя класса не совпадают.
- `HealthBase.cs` содержит старую или тестовую систему жизней и не используется как основная база.
- `Turret.cs` и `TurretSlowmo.cs` используют `UnityEditor.Handles` для gizmo-отрисовки радиуса. Для production build лучше обернуть этот код в `#if UNITY_EDITOR`.
- `Bullet.OnCollisionEnter2D()` ожидает, что объект столкновения имеет компонент `Health`.
- `FireScene` имеет отдельную runtime-логику создания базы и маршрутов, поэтому ее настройка отличается от обычного уровня.
